# Como importar um modelo deste repositório para o Overleaf

Para importar qualquer modelo deste repositório no Overleaf, siga estes passos:

1. Baixe a pasta do modelo desejado para o seu computador.
2. Compacte a pasta em formato `.zip`.
3. Acesse o Overleaf no navegador.
4. Clique em **New Project**.
5. Selecione **Upload Project**.
6. Envie o arquivo `.zip` criado.

Pronto! O projeto será importado e aberto no Overleaf.

## Dica

Antes de compactar, confirme se o arquivo principal do projeto (geralmente `main.tex` ou `dissertacao.tex`) está dentro da pasta do modelo.
